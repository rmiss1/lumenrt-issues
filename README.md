# Lumen RT — Bug Reports

This repository is the official place to report bugs and technical issues with **Lumen RT**, a hardware ray tracing mod for Minecraft Java Edition.

**This repository is primarily for bug reports.** Please keep general questions to a minimum. Feature requests and suggestions are not accepted here.

## Report a bug

**[Open a bug report](https://github.com/rmiss1/lumenrt-issues/issues/new/choose)**

Before submitting:

1. Make sure you're using the latest available Lumen RT build.
2. Search [existing issues](https://github.com/rmiss1/lumenrt-issues/issues) to avoid duplicates.
3. Try to reproduce the problem with only Lumen RT, Fabric API, and any mods necessary to trigger it, if possible.
4. Fill in the bug report form with clear steps to reproduce the problem.
5. Attach relevant logs and screenshots, if available.

## What to include

- Lumen RT version (including alpha/dev suffix, if any)
- Minecraft version and Fabric Loader version
- Operating system, GPU, and graphics driver version
- Other installed mods or resource packs relevant to the issue
- Expected and actual behavior
- Reproduction steps
- Logs or screenshots that show the issue

**Logs:** Please attach Minecraft's `latest.log` **and Lumen RT's own log files**, along with relevant crash reports, when available. Check all logs for personal information, usernames, file paths, access tokens, or other secrets before sharing.

## Compatibility reports

Reports involving other mods are welcome when they describe a reproducible rendering or compatibility bug. Please list the affected mods and their versions. A minimal mod setup is particularly helpful for isolating the root cause.

## Important

Lumen RT is in **alpha**, so bugs, visual artifacts, compatibility issues, and performance regressions may occur.

Opening an issue does not guarantee a fix or a specific timeline. Duplicate, incomplete, unrelated, or feature-request issues may be closed. Please keep questions brief and limited so the tracker stays focused on bugs.

**Do not upload executable files or private account information.**
